# Набросок «Туманные острова» (v0.2)

Играбельный прототип в браузере (three.js) — **эталон ощущений** для Godot-версии. Открой `fog-isles-standalone.html` двойным кликом. Опубликованная версия: артефакт «Туманные острова» в claude.ai.

## Что можно сделать (около 10 минут)
1. Отчалить от родного острова и плыть на огонёк в тумане (W/S — ход, A/D — руль, мышь с зажатой кнопкой — обзор).
2. У берега нажать **E — «Сойти на берег»**. Лодка остаётся на якоре, дальше пешком. На острове туман гуще.
3. Собрать хворост и живицу (они мерцают), **сделать факел**. Огонь в руке раздвигает туман.
4. По тропе подняться к вышке и **зажечь маяк**: туман откатывается, в музыке появляются аккорды.
5. Вернуться к лодке («Сесть в лодку»), доплыть до второго острова, зажечь факелом **три путевых фонаря** и второй маяк.
6. Ночь, северное сияние, колокола и хор. Дальше гулять свободно.

На телефоне: джойстик слева, обзор пальцем справа, кнопка действия появляется сама.

## Файлы
| Файл | Что это |
|---|---|
| `fog-isles-standalone.html` | Собранный набросок, работает без интернета |
| `src/main.js` | Весь код: сцена, туман, море, острова, лодка, пешая ходьба, факел, маяки, звук |
| `src/shell.html` | Разметка и стили (интро, HUD, финальная карточка) |
| `build.mjs` | Сборка: `npm install && npm run build` → `dist/` |
| `play.mjs` | Автопрогон всего пути с проверкой ошибок и скриншотами: `npm run play` (нужен Playwright) |

## Отладка из консоли браузера
`window.FOG` даёт доступ к состоянию и управлению:
- `STATE`;
- `teleport(x, z, yaw)` — перенести лодку;
- `walkTo(x, z, yaw)` — перенести игрока;
- `act()` — действие;
- `lightBeacon(i)`;
- `goal()` — текущая цель.

`window.__DT = 0.25` включает фиксированный шаг для автотестов.

## Как пользоваться при разработке
Числа камеры, тумана, лодки и порядок действий переносятся в Godot (карта соответствий в `.claude/skills/atmosphere-reference/SKILL.md`). **Код не переносится**: архитектура Godot-версии описана в `docs/04_TECH_SPEC.md`.
