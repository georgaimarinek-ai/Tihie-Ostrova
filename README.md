# Туманные острова (Fog Isles) — пакет для разработки на Godot

Уютная песочница на Поморском Севере. Плывёшь на карбасе от острова к острову, сходишь на берег с факелом и зажигаешь маяки. Каждый огонь раздвигает туман-Мгу, открывает новые земли и добавляет голос в музыку моря. Дома растёт усадьба. Опасность выбирает игрок: Тихий, Сказание или Сага.

## С чего начать
1. **Почувствовать игру:** открой `reference/sketch/fog-isles-standalone.html` в браузере и пройди его (около 10 минут).
2. **Посмотреть экраны:** `docs/mockups/*.png` (меню, плавание, остров, маяк, сумка, стройка, лоция, вечер у печи).
3. **Прочитать:** `docs/00_PITCH.md` (одна страница) → `docs/01_GDD.md` (правила и смысл).
4. **Открыть проект в Godot 4.7.2:** папка с `project.godot`. Сцена этапа 0 показывает остров в тумане; клавиша **L** зажигает маяк.
5. **Отдать Claude Code:** он читает `CLAUDE.md` сам. Начни с промпта этапа 1 из `docs/06_ROADMAP.md`.

## Что внутри
| Путь | Что это |
|---|---|
| `CLAUDE.md` | Правила проекта для Claude Code: где правда, команды, архитектура, «готово» |
| `.claude/skills/` | Навыки: `godot-verify`, `content-change`, `atmosphere-reference`, `model-import` |
| `docs/00…07` | Питч, GDD, контент (генерируется), баланс, техзадание, арт и звук, план работ, плейтесты |
| `docs/mockups/` | Макеты 8 экранов (1440×810) |
| `docs/images/` | Эталонные кадры Godot: до и после зажжения маяка |
| `content/*.json` | Весь контент и баланс, единственный источник чисел |
| `src/core/` | Логика без сцены: команды мира, сохранения, острова, туман, волны, инвентарь, крафт |
| `src/autoload/` | `Content`, `Net` (API коопа), `Game` (точка входа команд) |
| `src/world/`, `src/shaders/`, `src/scenes/` | Директор тумана, шейдеры (туман с просветами, вода, рельеф, объекты), сцена этапа 0 |
| `tests/` | 39 тестов на своём раннере, без аддонов |
| `tools/` | `verify.sh`, валидатор контента, модель прогресса, генератор документа контента |
| `art/` | Сюда художник кладёт `.glb` (правила в `docs/05_ART_AUDIO.md` §4) |
| `reference/sketch/` | Браузерный набросок: исходники, сборка, автопрогон |

## Проверка
```
godot --headless --path . --import      # один раз на свежем клоне
GODOT=godot tools/verify.sh              # контент, баланс, документ, тесты, сцена
```
Последний прогон: `content OK`, `targets OK`, `tests: 39, failed: 0`, `SMOKE OK`, `verify: OK` (Godot 4.7.2).
